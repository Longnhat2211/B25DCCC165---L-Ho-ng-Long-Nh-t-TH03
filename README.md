# ShopMini

Ứng dụng cửa hàng mini bằng React, TypeScript và Vite.

## Chạy ứng dụng

```bash
npm install
npm run dev
```

## Tài khoản demo

- Tên đăng nhập: nhập tên bất kỳ
- Mật khẩu: `123456`

## Công nghệ

- React Router
- Redux Toolkit
- Context API cho theme và authentication
- Dữ liệu từ https://fakestoreapi.com/products
